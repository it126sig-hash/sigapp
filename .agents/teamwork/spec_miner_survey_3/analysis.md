### 3.4 Discovered Edge Cases & Dirty Data Invariants
1. **Zero-Dates (`'0000-00-00'`) in Database**:

## 4. Conversion Calculation Formulations (R2)

### 4.1 Cohort-Based Real Conversion Formula (Authoritative R2)
Per user requirement:
> "Tampilkan konversi dari booking ke akad secara riil berbasis kode transaksi (bukan perbandingan kuantitas per bulan). Transaksi yang terkonversi ke akad mencakup transaksi yang mencapai status 'akad indent' maupun 'akad AJB'. Tampilkan persentase konversi ini pada tabel matriks bulanan (mengukur berapa persen transaksi booking pada bulan bersangkutan yang akhirnya mencapai akad) serta pada baris total tahunan."

For any given period (month $m$ or entire year):
$$\text{Konversi (\%)} = \frac{\text{Jumlah Transaksi Unik yang Booking pada Periode Tersebut dan Telah Mencapai Akad}}{\text{Total Transaksi Unik yang Booking pada Periode Tersebut}} \times 100\%$$

Where:
- **Denominator**: `COUNT(DISTINCT m.uniq_id)` where `booking_tgl` is within the period.
- **Numerator**: `COUNT(DISTINCT m.uniq_id)` where `booking_tgl` is within the period AND the transaction has reached Akad (either `m.akad = 1`, `m.akad_indent = 1`, `m.is_ajb IN ('PPJB', 'AJB')`, or valid non-zero `akad_tgl` / `akad_indent_tgl`), excluding `Batal`.
- If Denominator = 0, Konversi = `0.0%`.

### 4.2 Matrix Representation Comparison
There are two viable architectural models for the 6 status columns:

#### Model A: Status Cohort Distribution (Pure Cohort)
- Each row represents transactions booked in that month.
- The 6 columns show the **current distribution** of those bookings:
  $\text{Total Booking} = \text{Booking} + \text{Wawancara} + \text{SP3K} + \text{Batal} + \text{Akad Indent} + \text{Akad AJB}$.
- Conversion $\%$ equals $(\text{Akad Indent} + \text{Akad AJB}) / \text{Total Booking} \times 100\%$.
- Clicking on a status shows the transactions booked in that month that currently hold that status.

#### Model B: Status Event Activity (Activity Counts in Month) + Cohort Conversion
- The 6 columns show how many events occurred in that month:
  * Booking: bookings made in month $m$.
  * Wawancara: interviews conducted in month $m$ (`wawancara_tgl` in month $m$).
  * SP3K: approvals issued in month $m$ (`sp3k_tgl` in month $m$).
  * Batal: cancellations in month $m$ (`mkdt_batal_tgl` in month $m$).
  * Akad Indent: indent agreements done in month $m$ (`akad_indent_tgl` in month $m$).
  * Akad AJB: AJB deeds done in month $m$ (`akad_tgl` in month $m$).
- The **Konversi (%)** column displays the cohort conversion rate of the bookings made in month $m$.

*Recommendation*: Model A provides 100% additive integrity (columns sum up to row total) and perfectly aligns with the drilldown requirement in R3 ("Status Terakhir" and "Tanggal status terakhir"). Model B reflects historical monthly throughput. The verification SQL scripts below provide exact validation for both models.

### 5.2 Standalone SQL Verification Queries

#### Verification Query 1: Cohort Matrix & Conversion % for Year 2026 (Proyek 13)
```sql
SELECT 
  months.m AS bulan,
  COALESCE(data.total_booking, 0) AS total_booking,
  COALESCE(data.booking, 0) AS booking,
  COALESCE(data.wawancara, 0) AS wawancara,
  COALESCE(data.sp3k, 0) AS sp3k,
  COALESCE(data.batal, 0) AS batal,
  COALESCE(data.akad_indent, 0) AS akad_indent,
  COALESCE(data.akad_ajb, 0) AS akad_ajb,
  COALESCE(data.akad_total, 0) AS akad_total,
  CASE 
    WHEN COALESCE(data.total_booking, 0) > 0 
    THEN ROUND((data.akad_total / data.total_booking) * 100, 1) 
    ELSE 0.0 
  END AS konversi_persen
FROM (
  SELECT 1 m UNION SELECT 2 UNION SELECT 3 UNION SELECT 4 UNION SELECT 5 UNION SELECT 6 
  UNION SELECT 7 UNION SELECT 8 UNION SELECT 9 UNION SELECT 10 UNION SELECT 11 UNION SELECT 12
) months
LEFT JOIN (
  SELECT 
    MONTH(m.booking_tgl) AS bulan,
    COUNT(DISTINCT m.uniq_id) AS total_booking,
    SUM(CASE WHEN m.is_batal = 1 OR m.status_mkdt = 'Batal' THEN 1 ELSE 0 END) AS batal,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 1 OR (m.is_ajb = 'AJB' AND m.akad = 1)) THEN 1 ELSE 0 END) AS akad_ajb,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 0 OR m.akad IS NULL) AND (m.akad_indent = 1 OR m.is_ajb = 'PPJB') THEN 1 ELSE 0 END) AS akad_indent,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 0 OR m.akad IS NULL) AND (m.akad_indent = 0 OR m.akad_indent IS NULL) AND (m.sp3k = 1 OR (m.sp3k_tgl IS NOT NULL AND m.sp3k_tgl > '1970-01-01')) THEN 1 ELSE 0 END) AS sp3k,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 0 OR m.akad IS NULL) AND (m.akad_indent = 0 OR m.akad_indent IS NULL) AND (m.sp3k = 0 OR m.sp3k IS NULL) AND (m.wawancara = 1 OR (m.wawancara_tgl IS NOT NULL AND m.wawancara_tgl > '1970-01-01')) THEN 1 ELSE 0 END) AS wawancara,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 0 OR m.akad IS NULL) AND (m.akad_indent = 0 OR m.akad_indent IS NULL) AND (m.sp3k = 0 OR m.sp3k IS NULL) AND (m.wawancara = 0 OR m.wawancara IS NULL) THEN 1 ELSE 0 END) AS booking,
    SUM(CASE WHEN (m.is_batal = 0 OR m.is_batal IS NULL) AND m.status_mkdt != 'Batal' AND (m.akad = 1 OR m.akad_indent = 1 OR m.is_ajb IN ('PPJB', 'AJB')) THEN 1 ELSE 0 END) AS akad_total
  FROM mkdt m
  JOIN kavling k ON k.id_kavling = m.id_kavling
  JOIN jalan j ON j.id_jalan = k.id_jalan
  JOIN cluster cl ON cl.id_cluster = j.id_cluster
  WHERE cl.id_proyek = 13 AND YEAR(m.booking_tgl) = 2026
  GROUP BY MONTH(m.booking_tgl)
) data ON data.bulan = months.m
ORDER BY months.m;
```

#### Verification Query 2: Modal Detail Query & Data Shape Verification (Proyek 13)
```sql
SELECT 
  m.id_mkdt,
  m.id_kavling,
  m.uniq_id,
  TRIM(CONCAT(COALESCE(j.nama_jalan, ''), ' No. ', COALESCE(k.no_kavling, '-'))) AS kavling_label,
  COALESCE(c.sales, '-') AS sales_nama,
  COALESCE(c.nama_konsumen, '-') AS nama_konsumen,
  COALESCE(hj.id_tipe, t.tipe_rumah, '-') AS tipe_pricelist,
  CASE WHEN COALESCE(m.is_subsidi, 1) = 1 THEN 'Subsidi' ELSE 'Komersil' END AS badge_subsidi,
  m.booking_tgl,
  CASE 
    WHEN m.is_batal = 1 OR m.status_mkdt = 'Batal' THEN 'Batal'
    WHEN m.akad = 1 OR (m.status_mkdt = 'Akad' AND m.is_ajb = 'AJB') THEN 'Akad AJB'
    WHEN m.akad_indent = 1 OR m.is_ajb = 'PPJB' THEN 'Akad Indent'
    WHEN m.sp3k = 1 OR (m.sp3k_tgl IS NOT NULL AND m.sp3k_tgl > '1970-01-01') THEN 'SP3K'
    WHEN m.wawancara = 1 OR (m.wawancara_tgl IS NOT NULL AND m.wawancara_tgl > '1970-01-01') THEN 'Wawancara'
    ELSE 'Booking'
  END AS status_terakhir,
  COALESCE(NULLIF(TRIM(m.keterangan), ''), NULLIF(TRIM(m.keterangan_batal), ''), NULLIF(TRIM(m.keterangan_status), ''), '-') AS catatan_mkdt,
  CASE 
    WHEN m.is_batal = 1 OR m.status_mkdt = 'Batal' THEN 
      CASE WHEN m.mkdt_batal_tgl IS NOT NULL AND m.mkdt_batal_tgl > '1970-01-01' THEN DATE(m.mkdt_batal_tgl) ELSE NULL END
    WHEN m.akad = 1 OR (m.status_mkdt = 'Akad' AND m.is_ajb = 'AJB') THEN 
      CASE WHEN m.akad_tgl IS NOT NULL AND m.akad_tgl > '1970-01-01' THEN m.akad_tgl ELSE NULL END
    WHEN m.akad_indent = 1 OR m.is_ajb = 'PPJB' THEN 
      CASE WHEN m.akad_indent_tgl IS NOT NULL AND m.akad_indent_tgl > '1970-01-01' THEN m.akad_indent_tgl ELSE NULL END
    WHEN m.sp3k = 1 OR (m.sp3k_tgl IS NOT NULL AND m.sp3k_tgl > '1970-01-01') THEN 
      CASE WHEN m.sp3k_tgl IS NOT NULL AND m.sp3k_tgl > '1970-01-01' THEN m.sp3k_tgl ELSE NULL END
    WHEN m.wawancara = 1 OR (m.wawancara_tgl IS NOT NULL AND m.wawancara_tgl > '1970-01-01') THEN 
      CASE WHEN m.wawancara_tgl IS NOT NULL AND m.wawancara_tgl > '1970-01-01' THEN m.wawancara_tgl ELSE NULL END
    ELSE m.booking_tgl
  END AS tanggal_status_terakhir
FROM mkdt m
JOIN kavling k ON k.id_kavling = m.id_kavling
JOIN jalan j ON j.id_jalan = k.id_jalan
JOIN cluster cl ON cl.id_cluster = j.id_cluster
LEFT JOIN konsumen c ON c.id_konsumen = m.id_konsumen
LEFT JOIN hargajual hj ON hj.id = m.id_hargajual
LEFT JOIN tipe t ON t.id_tipe = k.id_tipe
WHERE cl.id_proyek = 13
ORDER BY m.booking_tgl DESC
LIMIT 20;
```

### Edge Cases
| # | Feature | Input | Observed Behavior |

| 1 | Date Filtering | Database record has `akad_tgl = '0000-00-00'` (31 rows in Proyek 13) | MySQL treats `'0000-00-00'` as NOT NULL; `YEAR()` returns 0. Strict mode fails equality comparison. Query must use `> '1970-01-01'` or `CAST NOT LIKE '0000%'`. |
